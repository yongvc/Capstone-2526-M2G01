# PCB Design

This directory contains the files related to the custom Printed Circuit Board (PCB) designed for the robot.

## Contents
- **Gerber Files**: `Capstone Agriculture Gerber_PCB1_2025-11-11.zip` - The production files to send to a PCB manufacturer (e.g., JLCPCB).
- **Interactive BOM**: `InteractiveBOM_PCB1_2025-11-29.html` - An interactive HTML file to assist with component placement and soldering. Open this in a web browser.
- **Schematic**: `SCH_Schematic1_1-P1_2025-11-21.png` - Image of the circuit schematic.
