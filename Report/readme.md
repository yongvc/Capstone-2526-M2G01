# Project Reports & Documentation

This directory contains project documentation and reports for the Lemon Harvesting Robot Capstone Project.

## Documents

| File | Description |
|------|-------------|
| `Technical_Report.txt` | Complete technical report with system design, implementation details, and team contributions |
| `Discussion Note (W1-W12).pdf` | Weekly discussion notes and meeting records |
| `Rules&RubricLime Harvesting Robot Challenge v9.pdf` | Competition rules and evaluation rubric |
| `System Block Diagram.png` | High-level system architecture diagram |

## Technical Report Summary

The Technical Report (`Technical_Report.txt`) contains:

1. **Introduction** - Problem statement and objectives
2. **Literature Review** - Existing solutions and market analysis
3. **Methodology** - CDIO framework and development approach
4. **System Design** - Hardware and software architecture
5. **Implementation** - Detailed component development
6. **Testing & Results** - Performance evaluation
7. **Future Works** - Planned improvements
8. **Conclusion** - Project outcomes and cost analysis
9. **Team Contributions** - Individual member contributions with code references
