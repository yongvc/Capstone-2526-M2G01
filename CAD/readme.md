# Mechanical Design (CAD)

This directory contains the SolidWorks (`.SLDPRT`, `.SLDASM`) files for the Lemon Harvesting Robot.

## Structure

The main assembly file is located in `final assembly 1/`:
- **Main Assembly**: `final assembly 1.SLDASM`

### Key Components
- **Arm Mechanism**: `Arm.SLDASM` - The robotic arm structure for connecting the chassis to the end effector.
- **End Effector/Gripper**:
    - `CutterHolder.SLDPRT`
    - `UScissor.SLDPRT`
    - `ServoScissorHolder.SLDPRT`
- **Chassis/Base**: `Base.SLDPRT`, `Cam Base.SLDPRT`
- **Drive System**: Stepper motors (`Assem1_stepper_motor.SLDASM`), pulleys, and belts.
- **Camera Mount**: `Camera Casing.SLDPRT`, `C260 WebCam Assembly.SLDASM`

## Usage
Open `final assembly 1/final assembly 1.SLDASM` in SolidWorks to view the complete robot assembly.
